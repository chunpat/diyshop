## 模板扩展方向

1. 包袋、书签、行李牌：先做固定图案 + 姓名 + 下方短句；不同商品单独定义印刷区域。
2. 家庭多人挂饰：人数决定图案槽位，每个槽位保存独立姓名。
3. 双照片首饰：照片区域分别裁切，外壳刻字使用另一个预览视图。
4. 照片、水彩、油画、漫画：需照片上传及处理流程，不能只用文字叠加模拟完成。
5. 满版服饰与围巾：需重复纹样、裁片安全区和不同角度的展示图。
