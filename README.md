# Callie storefront recreation

A responsive, buildless HTML/CSS/JavaScript recreation of the Callie gift storefront. Images are downloaded from the reference website for this requested design recreation.

## Preview

Run `npm run dev` and open http://localhost:5173.

## Included

- Desktop and mobile storefront, original reference banners and category artwork
- Banner controls, product browsing, text search, category filtering and price sorting
- Product customization with name preview and gift wrapping
- Wishlist and shopping bag with quantities and local persistence
- Local demo profile, newsletter, welcome offer and help forms

## Scope

Frontend demonstration only. Review order shows a summary, without payment or order submission. Inventory, shipping, authentication and fulfillment are not connected. Prices and images come from the reference site; ratings are sample data. Optional form entries stay in local storage.
